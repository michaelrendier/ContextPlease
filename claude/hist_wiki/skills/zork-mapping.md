# zork-mapping

**Skill:** `~/.claude/skills/zork-mapping/` · mirror `ContextPlease/claude/skills/zork-mapping/` · **Created:** 2026-11-17 (author: Cody Michael Allison): "make that version mapping into a Zork Mapping skill so I can use it for all of the Lost Treasures of Infocom, or any ZIL Z-machine."
The author's hand method for mapping Infocom games on one sheet of graph paper (3x3 per room, eight reserved pathway squares, U/D as diagonals, mazes and puzzles left out), as an algorithm with SVG and ASCII/Unicode outputs. Code: `ZorkMapper` repository. The ASCII conventions (two-character squares, `**` = 100, level colours, `╱╱` `╲╲` diagonals) and the planned viewer rules (centred current room, percentage geometry) are recorded in the skill.
