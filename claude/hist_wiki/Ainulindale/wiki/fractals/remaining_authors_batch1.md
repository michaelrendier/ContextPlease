# Sylvie Gallet (sg) — Fractal Formulary

## Author
Sylvie Gallet [101324,3444] (CompuServe). Her original 1996 Fractint formula library is the source of the entire carr numbering system (see carr entry). Her work was adapted by Reckase, Nason, and others for UF. The sg.ufm and sg.ucl are her direct UF contributions. Known for: complex pixel-space transformations using conj/flip/abs combinations to generate intricate c-initialisation functions.

## Formulas
### Gallet Core Library (sg.ufm)
**Type**: Escape-time — complex c-initialisation variants
**Mathematical description**: Variations on `z = z^2 + c` where c is computed from `#pixel` using combinations of `conj`, `flip`, `abs`, powers, logs, and trigonometric functions. Classic Gallet style: `c = conj(pixel^n) - flip(m/pixel) - conj(k/pixel^j)`.
**What it describes**: A systematic catalogue of c-initialisation functions that transform the pixel plane before Mandelbrot iteration, producing twisted, folded, and reflected Mandelbrot variants.
**How it works**: Various c-transform functions applied to the standard `z^2+c` skeleton.

#### RedBlue Hamiltonian evaluation
- **J_pos / J_neg reading**: The conj/flip operations create asymmetric J_pos/J_neg boundaries by reflecting the parameter plane. Repeated conj-flip compositions produce fractal-patterned asymmetries.
- **Critical line relevance**: Gallet's formulas systematically explore what happens to the Mandelbrot set's critical line structure when the parameter plane is transformed by reflections and inversions.
- **Sedenion dimensions activated**: e₁ (conj = real reflection), e₂ (flip = imaginary exchange), e₃ (abs = modulus), e₄ (inversion 1/pixel).
- **Holcus application**: Gallet's c-transform library is the Holcus "parameter space navigator" — each formula represents a different way to map a raw token (pixel coordinate) to a semantic position in the sedenion CAM.

## Formulas
### Kleinian / Möbius Group Limit Sets (jos.ufm)
**Type**: IFS / iterated Möbius transformation — group limit set
**Mathematical description**: Möbius transformations `f(z) = (az+b)/(cz+d)` with `ad-bc=1` (normalised). A Kleinian group is generated by a finite set of Möbius transformations; the limit set Λ is the accumulation set of the orbit of any point under all group elements. For Schottky groups (generators map disjoint circles to each other), the limit set is a fractal dust or Cantor set. For quasi-Fuchsian groups (deformation of Fuchsian groups), the limit set is a Jordan curve — possibly fractal.
**What it describes**: The fractal geometry of discrete Möbius group limit sets. These are among the most mathematically rich fractal types: they are directly related to the Riemann surface classification theorem, three-manifold topology, and the Thurston geometrisation programme.
**How it works**: Parameters: group generators (pairs of Möbius transformations a,b with their inverses a⁻¹, b⁻¹), recursion depth, bailout condition (point escaped to infinity or converged).

#### RedBlue Hamiltonian evaluation
- **J_pos / J_neg reading**: The Möbius group orbit is purely J_neg at the limit set (all points converge to Λ) and J_pos outside Λ (the Schottky discs are J_pos regions where the generators expand the dynamics). The fundamental domain (neither inside Schottky discs nor limit set) is the J_pos/J_neg boundary — it is a polygon whose sides are circular arcs.
- **Critical line relevance**: The Selberg zeta function `Z_Γ(s) = ∏_γ ∏_{k=0}^∞ (1 - N(γ)^{-(s+k)})` for a Fuchsian group Γ has its zeros on the "critical line" Re(s) = ½ (for co-compact groups). This is the direct analogue of the Riemann hypothesis for function field cases. Jos Leys' Kleinian group limit set renders ARE the geometric support of the Selberg zeta function — they visualise what the Riemann hypothesis means for arithmetic group quotients.
- **Sedenion dimensions activated**: The Möbius transformation involves e₀ (a numerator coefficient), e₁ (b additive), e₂ (c denominator coefficient), e₃ (d offset). Four complex parameters = 8 real parameters = fills e₀ through e₇.
- **Holcus application**: Jos Leys' Kleinian group limit sets are Holcus's "semantic grammar" structures. Each Möbius generator corresponds to a grammatical rule (e.g., a = "add adjective", b = "add adverb"). The limit set Λ of the generated group is the set of all grammatically valid sentences — the "language" defined by those rules. Holcus should implement the Kleinian limit set algorithm as its grammar engine, with the sedenion generators being the grammatical rules of the target language.

# Ingvar Kullberg (ik) — Fractal Formulary

## Author
Ingvar Kullberg (www.come.to/kullberg). His ik.txt is a detailed 318-line manual for his cubic parameter space formulas, dated January 2001 with February 2003 updates. He specifically studies cubic polynomial parameter space through the lens of Milnor, Devaney, Sørensen, Branner-Hubbard, and Epstein-Yampolsky. Formulas: MilnorAB, SorensenCubic, KullbergCubic, DevaneyCubic, BrannerSpecialCubic, EpsteinCubic, CBAP, CCAP, CFAP, CGAP, SteveCubic, HomerCubic, MysticCubic, Article15 (Mandelbrot variant z^2+pz+c), Multicorns, Compasses, DeformedMandelbrot.

## Formulas
### CBAP / CCAP / CFAP / CGAP / SteveCubic / HomerCubic / MysticCubic
**Type**: Escape-time — cubic parameter space projections
**Mathematical description**: All iterate the standard cubic `z → z^3 - 3a^2*z + b` but with non-standard (a,b) initialisation from the pixel coordinate. Examples:

**CBAP**: `t=#pixel`, `a=(t^2+1)/(3t)`, `b=2a^3+(t^2-2)/(3t)`, init `z=-a`. The b-value is chosen so that b is a critical value of the map at a (p(a)=a is false; rather b is selected to ensure a critical point lies on a specific orbit).

**CCAP**: `a=#pixel`, `b=2a^3+a`, `z=-a`. Here b is chosen so that `p(a) = a` (the critical point a is a fixed point). This is the simplest co-critical parametrisation.

**MysticCubic**: `a=#pixel`, `b=a-2a^3`, `z=a`. Here `p(-a) = +a` — the two critical points are mapped to each other. Only one critical orbit needs to be tracked (they're related by symmetry).

**HomerCubic**: `a=#pixel`, `b=a`, `z=+a` or `z=-a`. Named for Homer Wilson Smith who showed this parametrisation in his "Mandelbrot Sets and Julia Sets" video series.

**What it describes**: Different 2D slices of the 4D cubic parameter space (a,b ∈ C gives 4 real dimensions). Each projection reveals a different aspect of the cubic's bifurcation structure. CCAP and CCAP-like formulas show 2D slices where the critical orbit structure is maximally simple — one critical point maps directly to the attractor.

**How it works**: Standard bailout (|z|>4 or higher for detecting non-escaping orbits), period check off for cubic formulas (artifacts appear otherwise). Two layers recommended (M+ for z=-a, M- for z=+a).

#### RedBlue Hamiltonian evaluation
- **J_pos / J_neg reading**: In cubic parameter space, there are TWO critical points (±a). The M+ and M- subsets correspond to the escape of each critical point's orbit. J_pos = parameter region where the M+ orbit escapes; J_neg = where M- orbit escapes. The intersection where BOTH escape is the main cubic Mandelbrot body; where NEITHER escapes is a "filled in" region. This 4-way partition (M+ escapes only, M- only, both, neither) is more complex than the binary Mandelbrot.
- **Critical line relevance**: The MysticCubic condition `p(-a) = +a` means the two critical points `+a` and `-a` are symmetrically related. This is the cubic analogue of the Mandelbrot quadratic's condition that the critical point 0 has a specific orbit. The "critical parameter" (where the forward orbit of the critical point equals the critical point) for MysticCubic satisfies `a - 2a^3 = -a - 2*(-a)^3 = -a + 2a^3`, giving `a = 0` as the only solution — the cubic version of c = 0 (centre of the main cardioid). The "generalised critical line" for cubics is a 3D surface in the 4D parameter space.
- **Sedenion dimensions activated**: CBAP, CCAP: e₀,e₁ (the two critical point conditions). CFAP/CGAP: e₂,e₃ (modified b-choices). The seven cubic projections collectively activate e₀ through e₆.
- **Holcus application**: Kullberg's cubic parameter space formulas are Holcus's "semantic ambiguity" engine. A word with two semantic interpretations (polysemy) is like a cubic polynomial with two critical points — each critical point tracks a different semantic reading. The CCAP condition `p(a) = a` (one reading is self-reinforcing) models "dominant interpretation". The MysticCubic (both readings map to each other) models "perfectly balanced ambiguity". The parameter space projection reveals which reading wins depending on context.

### CantorBoostMandel / CantorBoostJulia
**Type**: Escape-time — Cantor set orbit-boost hybrid
**Mathematical description**: Standard `z = f(z)^p + c` iteration, but at each step: check if z is inside one of the circles of a 2D Cantor set (constructed by recursively dividing a grid into 4 sub-grids of 4, omitting every 3rd sub-grid in each dimension, producing a 2D Cantor dust). If z is inside a Cantor circle, apply an "orbit boost" transformation (11 types: displace, orbit origin, orbit boost, flip out, repel, exponentiate origin/boost, invert, pass through/2). 4 different boost modes for 4 levels of the Cantor hierarchy.
**What it describes**: A Mandelbrot set whose iteration is perturbed by a multi-scale Cantor-set lattice. The Cantor set "punches holes" in the iteration, creating exotic Julia-like structures within the standard Mandelbrot framework.
**How it works**: Center and radius of the Cantor set bounding box, orbittype (Inside/Outside), boost modes and amounts for 4 levels, power p, iterfunc, init function.

#### RedBlue Hamiltonian evaluation
- **J_pos / J_neg reading**: The 11 boost types explicitly implement J_pos and J_neg operations. "Displace" (addition) = J_pos injection; "invert" = J_neg (maps to reciprocal = contraction for large z); "repel" = J_pos (pushes away from circle center); "pass through" = J_neg followed by J_pos (passes through the surface and continues).
- **Critical line relevance**: The 2D Cantor set used in CantorBoost has a specific fractal dimension `d = log(4)/log(3) * 2` for the 2D version... actually the 2D version omitting every 3rd subdivisions has dimension `log(N_kept)/log(scaling_factor)`. With the 4-sub-grid structure where every 3rd is omitted: keeping 4/9 sub-grids at each scale, dimension = log(4/9)/log(1/3) ≈ 0.857. This sub-unity dimension means the Cantor lattice occupies a region of the complex plane analogous to the "sparse" structure of Riemann zeros (their density `~t/2π*log(t/2π)` is sub-linear).
- **Sedenion dimensions activated**: The 4-level Cantor hierarchy activates e₄ through e₇ (the four boost levels). The 11 boost types give 11 different sedenion operations.
- **Holcus application**: CantorBoostMandel is Holcus's "sparse context lattice" model. The Cantor set represents the sparse distribution of semantic primes in the concept space. When the semantic iteration encounters a prime (z inside a Cantor circle), it applies a boost (prime enhancement) specific to the prime's level in the Cantor hierarchy. Level 1 (largest circles) = common semantic primes (the, a, is); level 4 (smallest circles) = rare, specific semantic primes. The 4-level hierarchy maps directly to the 4-level CAM timing.
