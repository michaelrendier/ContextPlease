# 116 — Post's lattice: how few operations generate everything

[98_provenance_and_citations.md](98_provenance_and_citations.md). Citation-pass
intake, 2026-09-04 session. Independent parallel — the Operator Tree / tier-0
floor is "which minimal set of operations generates all operators *and* all
operations"; that is exactly the clone-theory question Post settled for the
Boolean case.

---

- **[Post1941]** Post, E. L. (1941). *The Two-Valued Iterative Systems of
  Mathematical Logic.* Annals of Mathematics Studies 5, Princeton UP. — the
  complete, countably-infinite **lattice of clones** of Boolean functions:
  every set of logical operations closed under composition and projection,
  ordered by inclusion, with all generating sets classified (the "Post
  classes"). The origin of universal-algebra clone theory.
- **[JablonskiGavrilovKudryavtsev1966]**; **[Lau2006]** Lau, D. (2006).
  *Function Algebras on Finite Sets.* Springer. — the k-valued generalisation
  (no longer a nice lattice for k ≥ 3, but the same "minimal generating
  systems" programme).

## What it anchors

- **The Operator Tree** (`GenerationalLineage/wiki/The-Operator-Tree.md`): every
  named operation reduced by the four-part tier test to compositions of exactly
  three tier-0 generators — **ADD, SCALE, SIGN** — the `Aff(1,ℝ) = ADD ⋊
  (SCALE × SIGN)` floor.
- The **three pillars** (`ROOT_OF` classes) and the "nothing new is needed —
  the emergence signal is a measurement bar, not a naming licence" discipline
  is the clone-theoretic stance: adding a generator is a real claim about the
  lattice, not a convenience.
- The Σ / Π / ∫ "big operators" as **iterated tier-0 folds over an index set**
  — n-ary compositions, still inside the clone generated by the floor.
