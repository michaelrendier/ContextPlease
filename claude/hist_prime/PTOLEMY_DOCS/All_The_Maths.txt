PURPOSE
-------
This document is a session primer for the Archimedes Maths code-generation
tiers (A–D). It records the full plan of attack for every file in
Ptolemy3/Archimedes/Maths/, including what exists, what is broken, what
is missing, and the exact methods/constants each file should contain.

STYLE RULES (apply to every file)
----------------------------------
- @staticmethod decorator on EVERY equation method (no self/cls)
- Module-level constants block at the TOP of each file (only constants
  relevant to THAT file's category)
- Optional-parameter solver style: def foo(p=None, V=None): ...
  Solve for whichever param is None from the others
- No multi-paragraph docstrings. One-line docstring max per method.
- Existing FibonacciSequence / Series pseudocode bugs must be fixed
  before adding new methods
- No import-time side effects (no loops, no prints outside
  if __name__ == '__main__')
