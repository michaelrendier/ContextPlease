PHASE 3 — QT VIEWER TARGET
================================================================================
Build: ainulindale_engine/engine/console_qt.py

Architecture:
  Single window, two panes:
    LEFT:  VisPy canvas — display modes: fano, complex_plane, 3d_cartesian
    RIGHT: Module list + equation selector + parameter controls
    BOTTOM LEFT: QTermWidget embedded shell (live Python console)
    BOTTOM RIGHT: Researcher options / output panel

Called by:
  python3 -m ainulindale_engine --qt
  or auto-detected when PyQt5 available

Layout sketch:
  +-------------------------+------------------+
  |  VisPy Canvas           |  MODULE LIST     |
  |  [fano/C-plane/3D]      |  + controls      |
  +-------------------------+------------------+
  |  QTermWidget shell      |  OUTPUT / INFO   |
  |  (live Python console)  |                  |
  +-------------------------+------------------+

Display modes per module (inversion module already provides viewer_data()):
  'complex_plane'  — polar plot (r, theta), inversion trajectory
  '3d_cartesian'   — 3D flow, VisPy scatter/line
  'fano'           — Fano plane (G2/SU(3) layer, octonion structure)
  'text'           — structured text, always available
  'sonification'   — future Phase 4

Each module's viewer_data(equation, params, display_mode) returns
renderer-ready data dict. Viewer just renders — modules supply the data.

Dependencies:
  PyQt5        — main window, layout, QTermWidget host
  vispy        — GPU canvas (OpenGL), all 3D and 2D displays
  qtconsole or qtermwidget — embedded Python shell
  No other external deps in engine core.

Ptolemy compatibility:
  --curses mode = /derivation shortcut, no Qt needed
  --qt mode = full viewer when Qt available
  Same program, same modules, different skin.
