README: how the galleries are made and named

Naming and grouping

  • Each gallery is named for what it shows (Abrikosov Atlas Gallery, Riemann–Fermat Atlas Gallery, Holcus 16D Paths Gallery); the file is <repo>/image_gallery/<Name>.html (the Holcus gallery: VAPMIP/holcus_paths_gallery/).
  • Groups follow the folder or file-name pattern of the images (an atlas per folder, a series per prompt); a group has a one-line blurb. Renaming or regrouping is a one-line edit in that gallery's gallery_config.json.
  • Identical files (same bytes) appear once, with the other paths listed as also at.

What each image page shows

Title, group, type, pixel size and file size, the date and commit it was added, where it is mentioned in the docs, the script that writes it, and a description (from the repository's own catalogue or captions, or the docstring of the writing script). The viewer zooms (wheel), pans (drag), steps (← →), and deep-links (#img=N, #g=Group).

Left out on purpose

  • Repository header images and application icons.
  • The TOTP enrolment code in VAPMIP (a secret).
  • Images embedded inside notebooks (they are not separate files).

Proprietary

The VAPMIP Gallery and the Holcus 16D Paths Gallery stay in the VAPMIP repository. This index only links to them and reads them at run time through the local server; it contains no VAPMIP image data.
