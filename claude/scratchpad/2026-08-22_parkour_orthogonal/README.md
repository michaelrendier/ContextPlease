# Parkour taught orthogonal before the algebra did — 2026-08-22, closing note

Cody: "i learned orthogonal in parkour... orthogonal reassignment of forward
momentum was least hindered directly perpendicular to foot placement being
chest and heart level on the wall."

Two physical principles, both exactly the session's mathematics, no new code
needed -- these are identities, not measurements:

1. DIRECTION: work = F.v (dot product). F perpendicular to v => F.v=0 =>
   ZERO work done against forward speed. This is literally i: the direction
   that redirects without costing anything on the existing axis. Same object
   as "the pathway equals i at the barycenter" (2026-08-22, same session) --
   i is defined as the direction along which motion is free.

2. CONTACT POINT: torque = r x F, r = lever arm from center of mass to
   contact point. Pushing THROUGH (near) the center of mass minimizes r,
   minimizing induced rotation -- all the impulse goes into translation, none
   wasted spinning you. Chest/heart level IS approximately center of mass.
   Same object as sigma = p_red/(p_red+p_blue), the barycenter, the point of
   least work to hold (2026-08-22, same session).

A parkour wall-redirect needs BOTH simultaneously: perpendicular push
direction (zero linear work loss, the i-rotation) AND contact through the
center of mass (zero torque, the barycenter) -- the two things this entire
session converged on abstractly, already known in the body before either was
written down as algebra.
