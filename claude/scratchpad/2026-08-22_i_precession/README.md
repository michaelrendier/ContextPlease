# i as precessional rotation; the Null Operator's lineage — 2026-08-22

Cody: "i is a rotation into an orthogonal plane... i has a generational
lineage, almost seems precessional... what is the generational lineage of
The Null Operator... is that also i."

Tested:
- i^4=1, order 4 (same order as L_(I|O), PW7).
- quaternion i,j,k anticommute (ij=-ji); composing rotations around different
  axes mixes components — genuine precession, not just spin.
- e0^2=+1 at EVERY dimension (1,2,4,8,16); every other basis vector squares to
  -1 (i-type). e0 is NOT i — it's the fixed point the i-lineage returns to.
- e0's generational lineage = the CD doubling itself: 0 new imaginaries at
  gen0 (root), +1 at gen1 (C), +2 at gen2 (H), +4 at gen3 (O), +8 at gen4 (S)
  = 15 total = |PG(3,2)|, matching R3/box-kite results already in the engine.
