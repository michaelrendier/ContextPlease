# "This algorithm changed how I think about compression" (3Blue1Brown, Information theory part 3, qbsb9DpdZ6s) — fetched 2026-11-20
Arithmetic coding: a text becomes one real number in [0,1): the unit interval is split by the model's next-character probabilities, recursively (chain rule), the receiver replays the same model to decode; code length k >= -log2 p(text) (Shannon information, rounded up); a language model's pre-training loss (cross-entropy) is the compressed size, so "next-token prediction" and "best compressor" are the same objective; prediction <-> compression equivalent (2^-delta from compressed-size differences); Hutter Prize scores the decoder size as well (a hard-coded Wikipedia is cheating), so a small model with the same prediction beats a big one; learning rate counts when the model is fine-tuned on the fly deterministically on both sides; practical versions: arithmetic coding (Elias 1960 idea, Rissanen and Pasco 1976) and asymmetric numeral systems (Duda 2013); explicit message length vs an end-of-message symbol is a design choice.
